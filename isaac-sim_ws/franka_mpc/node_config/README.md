Config folder for curobo_mpc_node.py with robot:=franka (the node loads mpc_override.yml from the robot_config's folder).
franka.yml: cuRobo 0.7.7's own content/configs/robot/franka.yml, with panda_link0 dropped from collision_link_names
(the fixed base stands on the mapped table top, so its spheres would always touch the map). mpc_override.yml: copy of
spot_operation_ros2/config/mpc_override.yml (the Spot node's MPPI smoothing), unchanged.

fr3.yml (the lab arm, Franka FR3 + Franka Hand; default since 10-14): generated by make_fr3_config.py from franka.yml
and franka_description 2.9.0 (fr3_* names, FR3 URDF in cuRobo's content tree assets/robot/fr3_description, joint limits
= the FCI's FR3 q_min/q_max, as in Isaac 6.0's FrankaFR3/fr3.usd; Panda spheres renamed, the right finger's turned with
its frame). check_fr3_config.py: FK and spheres equal the Panda config's (0.0001 mm), limits equal the FCI's.
Isaac check (check_fr3_isaac.py, runs/fr3_check): fr3.usd's fr3_hand vs cuRobo FK max 0.001 mm, 0 deg.
